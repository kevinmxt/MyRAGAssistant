# MyAIDemo2 — 本地知识库智能问答系统

## 项目简介

MyAIDemo2 是一个基于 RAG（检索增强生成）架构的本地知识库智能问答系统。用户可以将私有文档导入系统，系统自动对文档进行切分、向量化存储，用户通过自然语言提问即可获得基于知识库内容的精准回答。

## 技术栈

| 层次 | 技术 |
|------|------|
| 应用框架 | Javalin 6.4.0 |
| LLM 框架 | LangChain4j 1.12.1 |
| 向量数据库 | Milvus 2.x |
| 嵌入模型 | BGE-small-zh-v1.5 (ONNX) |
| 精排模型 | bge-reranker-v2-m3 (ONNX Cross-Encoder) |
| 文档解析 | Apache Tika |
| 构建工具 | Maven 3.9 |
| 运行环境 | JDK 21+ |

## 核心功能

1. **文档管理** — 支持 Markdown、TXT、PDF、DOCX、JSON 等多种格式的文档上传和解析
2. **自适应文档切分** — 根据文档结构自动选择最优切分策略（标题、段落、句子）
3. **多路召回** — Dense 向量召回 + Sparse 关键词召回 + Graph 知识图谱召回的并行检索
4. **查询增强** — 查询改写、HyDE（假设文档嵌入）、RRF 融合等多种查询优化策略
5. **Cross-Encoder 精排** — 使用 ONNX 模型的 bge-reranker-v2-m3 对召回结果进行精细排序
6. **知识图谱** — 集成 LightRAG 构建实体关系图谱，支持图谱增强检索
7. **上下文增强** — 检索到的文档片段自动添加文档标题等上下文前缀

## 系统要求

- JDK 21 或更高版本
- Maven 3.9+
- Docker（用于运行 Milvus 向量数据库）
- 至少 8GB 可用内存
