MyAIDemo2 版本更新日志

========================================
v1.3.0 (2026-08-06)
========================================
新增功能:
  - RAG 效果自动化评估管线，支持基线对比和退化检测
  - 评估指标: Recall@K, Precision@K, MRR, NDCG@K
  - 答案质量评估: Faithfulness (忠实度), AnswerRelevancy (答案相关性)
  - 支持多格式独立评估 (markdown/txt/pdf/docx/json)

========================================
v1.2.0 (2026-07-15)
========================================
新增功能:
  - 多路召回架构: Dense + Sparse + Graph 三路并行检索
  - LightRAG 知识图谱集成，支持图谱增强问答
  - RRF (Reciprocal Rank Fusion) 多路融合算法

优化:
  - Cross-Encoder 精排器升级为 ONNX 运行时，推理速度提升 3 倍
  - 文档切分管线增加自适应策略选择

========================================
v1.1.0 (2026-06-20)
========================================
新增功能:
  - 查询增强模块: 查询改写、HyDE 文档假设嵌入
  - 上下文增强器: 检索片段自动添加文档标题前缀
  - 支持 PDF、DOCX 格式文档解析

========================================
v1.0.0 (2026-05-01)
========================================
初始版本:
  - 支持 Markdown、TXT 文档上传和解析
  - 基于 BGE-small-zh-v1.5 的向量嵌入
  - Milvus 向量数据库集成
  - 基础 RAG 问答能力
